Camera help
This app cannot change browser permissions. For a dark preview in Samsung Internet:
  1. Open Samsung Internet Settings → Sites and downloads → Site permissions → Camera, then reset camera access for arvydas-hub.github.io.
  2. In phone Settings → Apps → Samsung Internet → Permissions → Camera, allow access while using the app.
  3. Confirm the phone's Camera access switch is on, return here, and tap Restart camera.
